# Florida General Contractor Campaign

## Campaign Overview

**Target Audience**: General Contractors in Florida who install windows, doors, and shutters
**Primary Action**: Need wind load calculations for building permits
**Conversion Path**: windload.co landing pages → windloadcalc.com (calculator/services)

## Why This Market?

1. **Regulatory Requirement**: Florida Building Code requires wind load calculations for window/door replacements
2. **High Volume**: Thousands of contractors doing this work daily
3. **Recurring Need**: Each project needs calculations - not a one-time purchase
4. **HVHZ Complexity**: Miami-Dade/Broward have strictest requirements = most confusion = most need for help
